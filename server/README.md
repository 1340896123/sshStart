# Portico SSH Sync Server

This service implements the cloud sync contract used by the Portico SSH desktop app. It authenticates accounts and stores only the opaque ciphertext generated by the desktop client.

## Requirements

- Node.js 24 or newer
- A random token signing secret of at least 32 bytes

## Run locally

```powershell
$env:PORTICO_SYNC_TOKEN_SECRET = node -e "process.stdout.write(require('node:crypto').randomBytes(32).toString('base64url'))"
npm start
```

The service listens on `127.0.0.1:8787` and writes its SQLite database to `data/portico-sync.sqlite` by default. Point Portico SSH at `http://127.0.0.1:8787`.

## Configuration

| Environment variable | Default | Purpose |
| --- | --- | --- |
| `PORTICO_SYNC_TOKEN_SECRET` | required | HMAC signing secret; use the same value on every replica |
| `PORTICO_SYNC_HOST` | `127.0.0.1` | Listen address |
| `PORTICO_SYNC_PORT` | `8787` | Listen port |
| `PORTICO_SYNC_DATABASE_PATH` | `./data/portico-sync.sqlite` | SQLite database path |
| `PORTICO_SYNC_TRUST_PROXY` | unset | Set to `true` only behind a trusted proxy that replaces `X-Forwarded-For` |

For an internet-facing deployment, terminate TLS at a reverse proxy, keep the service on a private network, and enable `PORTICO_SYNC_TRUST_PROXY` so authentication limits apply to the original client address. Back up the SQLite database and keep the token secret outside source control.

## API

- `POST /auth/register` creates an account and returns `{ "token", "email" }`.
- `POST /auth/login` verifies an account and returns `{ "token", "email" }`.
- `GET /sync/data` returns `{ "ciphertext" }`, or `404` before the first upload.
- `PUT /sync/data` stores `{ "ciphertext", "updatedAt" }` for the authenticated account.
- `GET /healthz` returns service readiness.

Passwords are hashed with scrypt and a per-account random salt. Tokens use HMAC-SHA256 and expire after seven days. Authentication endpoints are rate-limited per client address. Snapshot contents are never decrypted or parsed by the service.

## Docker

```powershell
docker build -t portico-sync .
docker run --rm -p 8787:8787 `
  -e PORTICO_SYNC_TOKEN_SECRET="replace-with-at-least-32-random-characters" `
  -v portico-sync-data:/data `
  portico-sync
```
