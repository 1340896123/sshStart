A FEW THINGS TO KNOW

开始之前。

还有其他问题？在 GitHub 提交反馈

目前支持哪些系统？

当前发布 Windows x64 安装包，面向 Windows 10 / 11，提供 EXE 与 MSI 两种格式。其他平台暂无官方发布包，请以 GitHub Releases 为准。

使用 SSH 功能需要注册吗？

不需要。安装后添加服务器即可使用 SSH 和 SFTP。云同步为可选功能，启用时需要配置同步服务并登录该服务。

AI 助手怎么接入？

在“设置 → 模型提供商”中配置兼容 OpenAI API 的服务地址、API 密钥和模型。支持 Chat Completions 与 Responses 模式，具体能力取决于提供商和模型；服务费用以提供商为准。

我的服务器数据会传到哪里？

SSH、SFTP 直接连接你配置的服务器。启用云同步后，加密快照会发往你配置的同步服务。使用 AI 时，消息和相关工具结果会发送到你选择的模型服务，请按需要配置权限。

如何验证下载的安装包？

下载上方 SHA256SUMS.txt，在 PowerShell 中运行 Get-FileHash .\sshStar_*_x64-setup.exe -Algorithm SHA256，将结果与校验文件中的对应条目比较。
